# Feature Catalog
This page distinguishes the current foundation from future ambitions. Confirm implementation in code before treating an item as shipped.

## Current foundation
- Kotlin Android application
- Jetpack Compose UI
- Eagle pose/state model and expression sprites
- Floating overlay concept using Android overlay permission
- Foreground service to maintain companion presence
- Draggable overlay and position persistence
- Autonomous movement between perches
- Idle/blink and expression animation controller
- CI debug APK workflow

## Planned creature features
- Coherent behavioral state machine
- Mood and personality traits
- Touch reactions and gestures
- Favorite perches and flight paths
- Micro-animations and richer idle loops
- Time-of-day behavior
- Optional sound and haptics
- Local relationship progression
- User-configurable activity level

## Planned companion features
- Authored dialogue bubbles
- Optional text-to-speech
- Optional AI conversation
- Focus/study mode
- Gentle, user-configured reminders
- User-triggered snapshot/photo mode

## Quality requirements
- Battery-aware idle behavior
- Pause/hide/mute controls
- Accessible controls and reduced motion
- Robust service lifecycle
- No intrusive or guilt-based engagement
- Privacy-preserving defaults
