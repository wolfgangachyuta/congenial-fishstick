# Personality & Behavior
## Creature-first philosophy
AURELION is an eagle companion, not a chat interface wearing an eagle costume. The most important expressions should be visual, physical, and contextual. Dialogue is optional.

## Proposed temperament dimensions
- **Curiosity:** how often it scans, tilts its head, or investigates.
- **Boldness:** how readily it performs energetic movement.
- **Calmness:** preference for long, quiet perches.
- **Sociability:** how frequently it acknowledges user interaction.
- **Energy:** current activity capacity (temporary state, not a moral score).

Keep personality traits distinct from temporary mood. A calm eagle can become excited; a curious eagle can still rest.

## Behavioral states (proposed)
- **Awake:** default low-intensity presence.
- **Curious:** scanning, head tilt, short investigation.
- **Wandering:** choosing a destination and moving.
- **Excited:** brief energetic reactions.
- **Resting:** long pauses, fewer movements.
- **Sleepy/Sleeping:** quiet animation and minimal activity.
- **Startled:** short response to a surprising user gesture, then recovery.

## Behavior principles
1. Avoid repetitive loops and immediate repeats.
2. Use weighted choice with cooldowns rather than pure random selection.
3. Separate behavior choice from animation execution.
4. Actions must be interruptible and cancel cleanly.
5. Respect pause, quiet hours, reduced motion, and user activity settings.
6. Never use guilt, punitive decay, streak pressure, or needy notifications.
7. Make relationship values inspectable and resettable.

## Example rhythm
Perch → glance around → idle → tiny feather ruffle → rest → user tap → acknowledge → settle. The cadence should feel spontaneous but not chaotic.
